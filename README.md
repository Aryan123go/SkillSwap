# SkillSwap

SkillSwap is a community marketplace for sharing skills. Find someone who can teach what you want to learn, and offer what you know in return.

## Getting started

```sh
npm install
npm run dev
```

Open the local URL printed by Vite to explore the app.

## Available scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build in `dist/`
- `npm run preview` — preview the production build locally
- `npm run lint` — check the project with Oxlint

## Current features

- Responsive skill discovery landing page
- Search people by name, location, or skills
- Filter profiles by skill category
- Profile cards with teaching and learning interests
- Swap and sign-up preview dialogs

## Built with

React and Vite.
